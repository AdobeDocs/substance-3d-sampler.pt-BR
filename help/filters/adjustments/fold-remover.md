## Parâmetros

<b>Parâmetros básicos</b>

* <b>Entrada lado a lado</b>: alternar\
  Ative essa configuração para garantir que esse filtro não quebre os materiais de revestimento.
* <b>Raio</b>: 0-50\
  Ajuste o raio para controlar o tamanho das dobras que o filtro tentará minimizar. Um raio baixo suavizará os detalhes mais finos.
* <b>Detalhes locais</b>: 0-1\
  Use um valor maior para manter os detalhes locais enquanto remove as dobras.

<b>Normal</b>

* <b>Substituir parâmetros comuns</b>: alternar\
  Controla os parâmetros deste canal individualmente.

<b>Height</b>

* <b>Substituir parâmetros comuns</b>: alternar\
  Controla os parâmetros deste canal individualmente.

<b>Máscara</b>

* <b>Máscara personalizada</b>: alternar\
  Ative o uso de uma máscara personalizada para controlar onde os efeitos desse filtro aparecem.
* <b>Máscara personalizada</b>: seleção de pincel/imagem\
  Crie ou selecione uma máscara personalizada.
* <b>Inversão de máscara personalizada</b>: alternar\
  Inverta a máscara.
