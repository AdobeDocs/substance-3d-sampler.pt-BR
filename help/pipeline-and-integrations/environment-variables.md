# Variáveis de ambiente

Esta página lista variáveis de ambiente que podem ser usadas para substituir o comportamento padrão do aplicativo.

| Variável | Descrição |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_LICENSE** | Valor: caminho para o arquivo license.keySubstitua o local de onde o aplicativo carrega o arquivo de licença.  **Observação:** versões anteriores à 3.0 usam este nome de variável:**SUBSTANCE\_ALCHEMIST\_LICENSE** |
