# Introdução

![](../assets/6.0_HomeScreen.png)

Ao abrir o Sampler, a <b>Tela Inicial</b> será exibida. A <b>Tela inicial</b> tem várias opções para ajudá-lo a começar um projeto novo ou existente do Sampler.

1. <b>Novo projeto</b>: crie um novo projeto importando um arquivo e escolhendo em uma coleção de ações rápidas.
1. <b>Início rápido</b>: crie um novo projeto vazio.
1. <b>Abrir</b>: abra um projeto com o navegador de arquivos do sistema.
1. <b>Página inicial</b>: acesse tutoriais recomendados, crie um novo projeto ou exiba uma lista de projetos recentes.
1. <b>Aprendizado</b>: acesse os tutoriais em vídeo e o conteúdo de aprendizado do Sampler.
1. <b>Arquivos</b>: exiba uma lista de projetos abertos recentemente.
1. <b>Sobre o Sampler</b>: saiba mais sobre sua versão do 3D Sampler.
1. <b>Documentação</b>: exiba a documentação e expanda suas habilidades.

Ao abrir, iniciar um novo projeto ou usar uma [ação rápida](../features-and-workflows/quick-actions.md), a <b>Tela inicial</b> desaparecerá para que você possa começar a criar ativos. Você pode abrir a <b>Tela Inicial</b> novamente pelo menu <b>Arquivo</b>.
