# Introdução

![](../assets/6.0_HomeScreen.png)

Ao abrir o Sampler, a **Tela Inicial** será exibida. A **Tela inicial** tem várias opções para ajudá-lo a começar um projeto novo ou existente do Sampler.

1. **Novo projeto**: crie um novo projeto importando um arquivo e escolhendo em uma coleção de ações rápidas.
1. **Início rápido**: crie um novo projeto vazio.
1. **Abrir**: abra um projeto com o navegador de arquivos do sistema.
1. **Página inicial**: acesse tutoriais recomendados, crie um novo projeto ou exiba uma lista de projetos recentes.
1. **Aprendizado**: acesse os tutoriais em vídeo e o conteúdo de aprendizado do Sampler.
1. **Arquivos**: exiba uma lista de projetos abertos recentemente.
1. **Sobre o Sampler**: saiba mais sobre sua versão do 3D Sampler.
1. **Documentação**: exiba a documentação e expanda suas habilidades.

Ao abrir, iniciar um novo projeto ou usar uma [ação rápida](../features-and-workflows/quick-actions.md), a **Tela inicial** desaparecerá para que você possa começar a criar ativos. Você pode abrir a **Tela Inicial** novamente pelo menu **Arquivo**.
