# Atalhos

Essa página lista todos os atalhos de teclado disponíveis e suas ações.

## Atalhos globais

| *Ação* | *Windows* | *MacOS* |
| --- | --- | --- |
| Desfazer | Ctrl + Z | ⌘ + Z |
| Refazer | Ctrl + Shift + Z | ⌘ + Shift + Z |
| Salvar | Ctrl + S | ⌘ + S |
| Salvar como | Ctrl + Shift + S | ⌘ + Shift + S |
| Exportar | Ctrl + E | ⌘ + E |
| Somente Visualização 3D | 3 | 3 |
| Somente Visualização 2D | 2 | 2 |

## Atalhos do Visualização 3D

| *Ação* | *Windows* | *MacOS* |
| --- | --- | --- |
| Rotação da câmera | Alt + Mouse para a esquerda ou Mouse para a esquerda | Option + Mouse para a esquerda ou Mouse para a esquerda |
| Panorâmica da câmera | Alt + Mouse no meio ou Mouse no meio | Option + Mouse no meio ou Mouse no meio |
| Zoom da câmera | Alt + Mouse para a direita ou Roda do mouse | Option + Mouse para a direita ou Roda do mouse |
| Foco | F | F |
| Rotação do ambiente | Shift + Mouse para a direita | Shift + Mouse para a direita |
| Visibilidade do ambiente | 1 | 1 |
