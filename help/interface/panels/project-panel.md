# Painel Projeto

![](../../assets/Project-panel-gen.png)

Os projetos no Sampler funcionam como pacotes que podem armazenar vários ativos. O **painel Projeto** exibe os materiais que compõem o seu projeto atual.

Os controles na parte superior do painel Projeto permitem adicionar ou gerenciar materiais no projeto atual:

* Use o botão **Adicionar** para abrir o **menu de predefinição de material** e adicionar um novo material ao projeto.
* Use o botão **Duplicar** para duplicar o material atualmente selecionado.
* Use o botão **Renomear** para renomear o material atualmente selecionado.
* Use o botão **Excluir** para excluir o material atualmente selecionado.

>[!NOTE]
>
> Você também pode clicar com o botão direito do mouse em qualquer material para Renomear, Excluir ou Duplicar.

Clique em um de seus ativos para carregá-los no **Visor** ou arraste um material para o **painel Camadas** para usá-lo em outros materiais.
