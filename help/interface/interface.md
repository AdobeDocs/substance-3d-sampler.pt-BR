# Interface

A área de trabalho do Sampler é composta pelas portas de visualização 2D e 3D, pelas barras laterais esquerda e direita e por uma coleção de painéis. Cada painel é dedicado a uma finalidade específica, para que diferentes painéis sejam úteis durante diferentes partes do processo criativo.

## Personalizar a área de trabalho

O espaço de trabalho do Sampler é totalmente personalizável, para que você possa encontrar um layout que funcione melhor para você. Se você quiser redefinir os painéis para o layout padrão, use **Janela > Redefinir para o layout padrão**.

## Reorganizar painéis

Clique e arraste o título de um painel para começar a movê-lo.

Você pode encaixar um painel nas bordas da janela de visualização ou em outros painéis: arraste o painel sobre a borda em que deseja encaixá-lo e uma guia de realce azul será exibida. Quando a linha aparecer, solte o painel para encaixá-la.

## Abrir e fechar painéis

Use o X no canto superior direito de um painel para fechá-lo. Os painéis fechados são armazenados nas barras laterais.

Para abrir um painel novamente, clique no ícone relevante do painel na barra lateral esquerda ou direita. Isso abre o painel temporariamente. Arraste o painel para fora para mantê-lo aberto permanentemente.

## Menus do aplicativo

A **barra de menus do aplicativo** mostra o nome do projeto atual. Ele também contém os menus **Arquivo**, **Editar**, **Janela**, **Ajuda** e **Licença**.

Use o menu <b>Arquivo</b> para criar um novo projeto, abrir um projeto existente ou salvar ou exportar o projeto atual.

Use o menu <b>Editar</b> para desfazer e refazer ações ou abrir as [Preferências](../interface/preferences/preferences.md).

Use o menu <b>Janela</b> para redefinir o espaço de trabalho para o layout padrão.

Use o menu <b>Ajuda </b> para saber mais sobre o Sampler ou descobrir como corrigir problemas.

| Documentação da API Python | Saiba como usar a API Python do Sampler para automatizar tarefas. |
| Atalhos de teclado | Veja uma lista completa de atalhos de teclado. Usar atalhos pode ajudá-lo a trabalhar mais rápido do que depender apenas do cursor. |
| Boas-vindas | Abra a <b>janela de Boas-vindas</b> para saber mais sobre as possibilidades no Sampler. |
| Novidades | Abra a <b>janela Novidades</b> para ver o que mudou na versão mais recente do Sampler. |
| Notas de versão | Veja o que mudou nas versões recentes do Sampler. |

| Relatar um erro | Relate um problema com o Sampler. |
| Exportar log | Isso pode ser útil para solucionar problemas que possam ocorrer ao usar o Sampler. |
