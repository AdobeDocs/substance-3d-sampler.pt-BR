# Scripts e desenvolvimento

O Adobe Substance 3D Sampler oferece suporte a plug-ins personalizados por meio da API Python do Sampler. Os plug-ins podem ser úteis para todos os usuários do Sampler, desde a automação da criação de materiais para grandes bibliotecas de materiais até a execução automática da configuração de novas instalações ou a adição de novas funcionalidades.

A documentação completa da API está incluída ao instalar o Sampler. Você pode abrir a documentação da API no Sampler:

* Use Ajuda > Documentação da API Python... para abrir a documentação.

* [Gerenciar plug-ins e scripts instalados](manage-installed-plugins-and-scripts.md)
* [Criar um plug-in com Python e QML](create-a-plugin-with-python-and-qml.md)
* [Criar um script com Python](../scripting-and-development/create-script-with-python/create-a-script-with-python.md)
