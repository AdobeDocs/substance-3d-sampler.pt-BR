# Trabalhar com os canais de revestimento

Como o nome sugere, os canais de revestimento permitem adicionar um revestimento ao material. Os revestimentos podem ter seu próprio valor de aspereza, o que pode afetar a aspereza de base do material, ajudando a criar efeitos como uma superfície envernizada ou polida. Assista ao vídeo abaixo para saber como usar o canal de revestimento no Sampler para criar um material de assoalho envernizado do zero.
