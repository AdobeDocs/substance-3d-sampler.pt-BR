# Fluxos de trabalho gerados

O Substance 3D Sampler ajuda você a iterar rapidamente e experimentar novas ideias com facilidade usando três recursos generativos atualmente em beta: Texto para textura, Texto para padrão e Imagem para textura.

![](../assets/genai-banner.png)

## Texto para textura

O recurso Texto para textura permite experimentar rapidamente as ideias que você tem para gerar texturas de um prompt de texto.

Para usar Texto para textura:

1. Abra o painel <b>Gerativo (Beta) </b> na barra de ferramentas à esquerda.
1. Escolha “<b>Textura</b>” na lista suspensa Tipo.
1. Escreva um prompt de texto que descreva a textura que você deseja criar.
1. Use <b>Gerar</b> para começar a gerar texturas. Cada uso do recurso gerará quatro variações.
1. Você pode arrastar e soltar o resultado desejado nas exibições 3D ou 2D para abrir o <b>modelo de criação de material</b> ou <b>adicioná-lo às camadas</b> por meio do botão dedicado. Você também pode adicionar o resultado aos seus <b>Ativos</b> para encontrá-lo facilmente mais tarde.

Você pode então usar o resultado como faria com qualquer outra textura, por exemplo, executar Imagem para material e adicionar filtros adicionais sobre ele.

### Text-to-Pattern

O recurso Texto para padrão permite gerar padrões rapidamente a partir de um prompt de texto para que eles possam ser aplicados em qualquer superfície desejada.

Para usar Texto-para-Padrão:

1. Abra o painel <b>Gerativo (Beta) </b> na barra de ferramentas à esquerda.
1. Escolha “<b>Padrão</b>” na lista suspensa Tipo.
1. Escreva um prompt de texto que descreva o padrão que você deseja criar.
1. Use <b>Gerar</b> para começar a gerar padrões. Cada uso do recurso gerará quatro variações.
1. Você pode adicioná-lo como uma entrada de um <b>filtro de padrão</b> ou diretamente às <b>camadas</b> por meio dos botões dedicados. Você também pode adicionar o resultado à sua biblioteca de <b>Ativos</b> para encontrá-lo facilmente mais tarde.

#### Imagem-para-textura

A <b>Imagem para Textura</b> cria quatro proposições de <b>texturas quadradas e lado a lado</b> de qualquer <b>imagem de referência</b>, independentemente da proporção. Ele pode permitir que você <b>gere variações</b> de texturas que já possui ou crie texturas prontas para uso a partir de imagens de referência suas.

Para usar Imagem para textura:

1. Abra o painel <b>Gerativo (Beta) </b> na barra de ferramentas à esquerda.
1. Escolha “<b>Textura</b>” na lista suspensa Tipo.
1. Arraste e solte sua <b>imagem no campo de texto</b> ou clique no ícone “Adicionar imagem” para abrir o explorador de arquivos e selecionar a imagem que deseja usar como referência.
1. Use <b>Gerar</b> para começar a gerar texturas inspiradas na imagem de referência. Cada uso do recurso gerará quatro variações.
1. Você pode arrastar e soltar o resultado desejado nas exibições 3D ou 2D para abrir o <b>modelo de criação de material</b> ou adicioná-lo às <b>camadas</b> por meio do botão dedicado. Você também pode adicionar o resultado aos seus <b>Ativos</b> para encontrá-lo facilmente mais tarde.

## Dicas para escrever prompts de textura ou padrão

Adicione ao campo de entrada <b>palavras ou expressões</b> que descrevem a <b>textura</b> ou o <b>padrão</b> que você deseja gerar. Ser específico dará a você mais controle sobre os resultados gerados.

Para <b>excluir</b> um ou vários prompts específicos, você pode adicionar até 10 palavras ou expressões para evitar ao processar seu prompt. Escreva “<b>—no</b>” antes das palavras ou expressões que deseja excluir. 

Você também pode usar <b>Amostras</b> no painel Generativo (Beta) para começar a explorar ideias de prompt.

## Créditos generativos

Os recursos generativos do Sampler não usam créditos enquanto os recursos estão na versão beta.

Consulte as <b>Perguntas frequentes sobre crédito generativo</b> para obter as informações mais recentes sobre como os créditos generativos funcionam nas ferramentas Adobe.
