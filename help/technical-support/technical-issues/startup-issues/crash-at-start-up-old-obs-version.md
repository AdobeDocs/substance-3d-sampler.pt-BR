# Falha na inicialização - Versão antiga do OBS

O aplicativo pode falhar na inicialização devido a uma versão antiga do [OBS](https://obsproject.com/fr) instalada.

Para resolver esse problema, atualize a [versão do OBS](https://obsproject.com/fr/download) ou desinstale-a.
