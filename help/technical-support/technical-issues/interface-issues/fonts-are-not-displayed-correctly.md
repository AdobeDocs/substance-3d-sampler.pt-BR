# As fontes não são exibidas corretamente

Se você estiver no Windows 10 Enterprise e usar o recurso [Bloquear fontes não confiáveis](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise), poderá seguir este [tutorial](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html) para excluir o Sampler da lista de aplicativos não confiáveis para bloqueio de fontes.
