# Artefatos visuais de Imagem para material

Os resultados da <b>Imagem para material (alimentada por IA)</b> às vezes podem ser alterados (principalmente cores erradas).

Habilite ou desabilite as *Redes Neurais aceleradas por GPU* na seção<b> Aprendizado de máquina</b> das Preferências do Substance 3D Sampler para resolver o problema.
