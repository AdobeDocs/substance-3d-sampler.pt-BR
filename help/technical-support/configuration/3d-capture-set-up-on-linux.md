# Instalação do captura 3D no Linux

Para usar o <b>captura 3D</b> no Linux, você precisará instalar o <b>Wine 8</b> com uma conta de administrador.

Ubuntu

apt-get install wine

Red Hat Enterprise Linux (RHEL 8)

sudo subscription-manager repos —enable codeready-builder-for-rhel-8-x86\_64-rpms

dnf instalar vinho

Red Hat Enterprise Linux (RHEL 9)

sudo subscription-manager repos —enable codeready-builder-for-rhel-9-x86\_64-rpms

dnf instalar vinho
