# 0.5.0

Data de lançamento: **2019/02/28**

Adicionado:

* [Pilha de camadas] Reordenação de camadas
* [Pilha de camadas] Excluir uma camada oculta
* [Pilha de camadas] Importar um material diretamente na posição de sua escolha
* [Pilha de camadas] Entrada de material como um novo tipo de parâmetro de filtro
* O orçamento do Substance Engine [Performance] é dinâmico para melhorar o desempenho
* [Desempenho] Melhor desempenho do OpenGL, especialmente no MacOS
* [Dados] Atualização de dados mais rápida após o lançamento de uma nova versão
* [Content] AI Delighter disponível no Windows 7 e no Windows 8
* [Content] AI Delighter disponível na GPU RTX

Corrigido:

* Corrigir possíveis falhas ao sair do aplicativo
* Exportar pop-up abre mais rapidamente ao exportar grandes coleções

Problemas conhecidos:

* O uso de múltiplos delighters em um material não é recomendado
* O Delighter trava com drivers NVIDIA mais antigos (menos de 400.x)
* Alternar a visibilidade rápida de um estágio Delighter afetará o desempenho
* Falha ao carregar seu próprio ambiente
